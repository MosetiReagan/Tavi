# Independent offline speech

Settings → Assistant language offers optional, user-initiated, resumable downloads for Whisper Tiny int8 English recognition, Omnilingual 300M int8 Kiswahili recognition, and Piper English/Kiswahili voices. All files have pinned revisions, byte counts, and SHA-256 checks in `app/src/main/assets/local-model-packs.json`. An incomplete or modified pack cannot be loaded. The packs live in private `files/local_packs`; recordings remain in memory and are never saved. Remove also discards unfinished downloads.

Recognition uses 16 kHz mono microphone capture, a silence endpoint, a seven-second initial speech timeout, and a thirty-second recording limit. Select English or Kiswahili; Device uses the device language, with English as the fallback for other languages. Kiswahili requires its own recognition pack; the compact English pack is not silently used for it. Short Kiswahili and mixed-language utterances can still be inaccurate. Recognition supplies a final transcript rather than live partial text. Cancellation suppresses a pending decode result and closes the microphone; native handles are released after the running bounded decode finishes. Audio focus, follow-up windows, and explicit stop controls remain in the voice session.

Whisper, Omnilingual, and Piper inference run on the CPU with two threads. Models load on demand and release after 45 seconds idle or on memory pressure. Installed packs take priority over Android providers. Without packs, an installed Android on-device recognizer/voice remains an offline fallback; text is always available. Synthesis is divided into bounded text segments and audio playback stops on cancellation. The Kiswahili pack is the Congolese `sw_CD` Lanfrica voice, not a Kenyan accent claim.

## Runtime and model provenance

The speech runtime is sherpa-onnx **v1.12.20**, using its publisher's statically linked ONNX Runtime AAR. Builds verify SHA-256 `c8a88a8390ea699b24c49a31c56e8b2e3515c5cd5a2a49f8555a3b3fd68d253a`. An offline build can pass `-PtaviSpeechAar=/absolute/path/to/the/verified.aar`; the same hash check applies.

- [sherpa-onnx source, release, and build workflows](https://github.com/k2-fsa/sherpa-onnx/tree/v1.12.20); Apache-2.0. License bundled at `assets/third-party/sherpa-onnx-LICENSE`.
- [ONNX Runtime source](https://github.com/microsoft/onnxruntime), MIT, linked by the publisher's speech runtime.
- [eSpeak NG source](https://github.com/espeak-ng/espeak-ng), GPL-3.0-or-later, used by Piper phonemization. Full GPL text is bundled at `assets/third-party/espeak-ng-COPYING`. The original Tavi source license does not replace the GPL terms for eSpeak or its data. Distribution of a combined APK must satisfy those terms, including corresponding source obligations.
- [Whisper Tiny conversion](https://huggingface.co/csukuangfj/sherpa-onnx-whisper-tiny), pinned revision `65176e2deb88badc814a94058666cadccc29b61c`; [original Whisper source/model license](https://github.com/openai/whisper/blob/main/LICENSE), MIT.
- [Omnilingual 300M CTC int8 conversion](https://huggingface.co/csukuangfj/sherpa-onnx-omnilingual-asr-1600-languages-300M-ctc-int8-2025-11-12), pinned revision `6abf1ece20cd2308bdb7d13cd78ec1c44fa4c094`; Meta Apache-2.0 notice is included in the verified pack. Approximately 365 MB download. On three preselected human Kenyan Kiswahili FLEURS clips, it had 21/83 word errors (25.3%), compared with Tiny 83/83 and Small 60/83. This small CPU reference comparison is not a population accuracy estimate; short synthetic speech remained poor. The Android regression fixture checks human speech separately from voice generation.
- [English Lessac model card](https://huggingface.co/csukuangfj/vits-piper-en_US-lessac-low/blob/7f5edb341cadf35daab356f857ed5ae8545d22bf/MODEL_CARD) links the [Lessac dataset terms](https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html).
- [Kiswahili Lanfrica model card](https://huggingface.co/csukuangfj/vits-piper-sw_CD-lanfrica-medium/blob/627325ced1dfadc02e5e2b6c1b2dbe546e66485f/MODEL_CARD) links [Lanfrica dataset terms](https://lanfrica.com/record/kiswahili-tts-dataset). The voice was fine-tuned from an English Lessac model. Both cards are included in the downloaded packs; no uniform license is asserted for these voice weights or datasets.

Downloads contact GitHub or Hugging Face and their HTTPS delivery hosts. No recording, transcript, note, or document is included in a pack download request. Opening Source & terms opens the browser explicitly. Model binaries are not committed to the repository.
